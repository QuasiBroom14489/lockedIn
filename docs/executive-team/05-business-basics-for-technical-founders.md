# Business Basics for Technical Founders (lockedIn)

This is a quick translation guide from business language to builder language.

## Core Terms in Plain English
- `Retention`: do users come back after trying the app?
- `D7 Retention`: percent of new users who return 7 days later.
- `WAU`: how many unique users were active this week.
- `Activation`: first moment user gets core value (for lockedIn: completes a focus session and sees useful peer learning content).
- `Monetization`: how you make money.
- `Go-to-market (GTM)`: how you get users.
- `Traction`: proof people are using and returning to the product.

## Simple Decision Framework
Before building a feature, ask:
1. Does this improve retention, growth, or revenue in the next 4-6 weeks?
2. How will we measure success?
3. What is the smallest version we can ship in 1-2 weeks?

If you cannot answer these clearly, delay the feature.

## Recommended Weekly Targets (Early Stage)
- `WAU`: growing every 1-2 weeks
- `D7 retention`: trending toward `25-35%+`
- `Sessions per active user`: trending up each month
- `Crash-free rate`: `99%+`

## Founder Priorities (Order)
1. Product reliability
2. Retention
3. Growth loop
4. Monetization tests
5. Fundraising materials

## Common Mistakes to Avoid
- Building too many features before retention improves.
- Running growth campaigns before onboarding is solid.
- Tracking too many metrics and losing focus.
- Pitching without clear weekly/monthly usage trend data.

## Your Default Weekly Plan
- Build one high-impact product improvement.
- Run one user-growth experiment.
- Fix one reliability issue.
- Review metrics and cut low-impact work.
