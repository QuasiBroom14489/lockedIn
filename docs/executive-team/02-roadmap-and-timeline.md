# lockedIn Simple Plan (6 Months)

This is the plain-English version of your roadmap.  
Start date: week of February 23, 2026.

## Main Goal
Build an app where students learn from each other, study more effectively, and improve together every week.

## 5 Numbers to Track (Only These)
- `Weekly Active Users (WAU)`: how many students used the app this week.
- `D7 Retention`: of students who joined, how many came back 7 days later.
- `Sessions per Active User`: average completed sessions per active student.
- `Invite Rate`: average invites sent per active student.
- `Crash-Free Rate`: percent of app sessions without crashes.
- `Peer Value Actions`: saves/shares of study tips, stacks, or useful posts.

## Phase 1 (Weeks 1-4): Make Core Product Solid
Focus: app quality and basic growth tracking.

Ship:
- Finish social feed work already identified in your implementation notes.
- Add analytics events for signup, first session, completed session, invite sent.
- Tighten Firebase rules and validation.
- Add crash/error monitoring.

Success by end of Phase 1:
- Crash-free rate at or above `99%`.
- At least `95%` of test users can complete a full session without blockers.

## Phase 2 (Weeks 5-8): Run a Controlled Campus Beta
Focus: real users, real feedback.

Ship:
- Recruit `50-100` Notre Dame students.
- Add simple referral flow.
- Add in-app feedback button.
- Run one onboarding test each week.

Success by end of Phase 2:
- `WAU >= 60`
- `D7 retention >= 25%`
- Retained users average `3+` sessions/week

## Phase 3 (Weeks 9-14): Improve Retention
Focus: get students to come back each week.

Ship:
- Streaks and friend nudges.
- Better anti-cheat checks.
- Better profile value (study highlights, useful social proof).
- Improve "learn from others" loop (best tips, best stacks, easy save/share).
- Community rules and moderation basics.

Success by end of Phase 3:
- `D7 retention >= 35%`
- `WAU >= 150`
- Invite rate `>= 0.25`

## Phase 4 (Weeks 15-20): Test Monetization
Focus: learn if users will pay and for what.

Ship:
- Test one premium offer at a time (example: advanced analytics or premium customization).
- Run pricing survey.
- Create campus ambassador playbook.
- Standard weekly advisor update with key metrics.

Success by end of Phase 4:
- One premium test with `2-3%` conversion.
- `WAU >= 300` with stable or improving retention.

## Phase 5 (Weeks 21-24): Package for Fundraising or Partnerships
Focus: tell a clean traction story.

Ship:
- Final deck with real numbers.
- 12-month growth and hiring plan.
- Pilot proposal for 2-3 additional campuses.

Success by end of Phase 5:
- Clear 12-week metric trend line.
- Repeatable process for launching new campus pilots.

## Your Weekly Founder Routine (Simple)
- Monday (45 min):
  - Pick top 3 outcomes for the week.
  - Pick one feature, one growth test, one quality fix.
- Wednesday (30 min):
  - Check if this week’s work is shipping on time.
  - Cut lower-priority tasks early.
- Friday (45 min):
  - Record the 5 numbers.
  - Write what worked, what failed, what changes next week.

## Rule for Scope Control
If a task does not help one of the 5 numbers in the next 4-6 weeks, delay it.
